# Calculadora-de-kwh.-
### projeto de cálculo de kWh e consumo mensal finaceiro.
Criado a partir da linguagem Python.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

A fórmula usada para se obter o kWh: Watts * Tempo diaŕio de uso * 30 / 1000.

![Fórmula Consumo](https://img.shields.io/badge/kWh%2Fm%C3%AAs-Watts%20x%20Tempo%20di%C3%A1rio%20x%2030%20%2F%201000-green?style=for-the-badge)

Para se obter o cálculo do valor gasto aproximado mensalmente usa-se a fórmula: kWh * 0,75.

Para executar o programa, adcione o aparelho, a potência, e o tempo de uso diário em horas do mesmo.

Criado para fins de estudo.
